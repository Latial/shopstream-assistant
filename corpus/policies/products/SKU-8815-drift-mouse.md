# Drift Wireless Mouse (SKU-8815)

Lightweight wireless mouse for everyday and office use.

**Price: €49**

## Specifications

| Attribute | Value |
|---|---|
| Sensor | 12,000 DPI optical, five stored steps |
| Connection | 2.4 GHz dongle and Bluetooth 5.1 |
| Battery life | 70 hours per charge |
| Charging | USB-C, 90 minutes to full |
| Weight | 78 g |
| Colours | Black, White, Sand |

## In the box

Mouse, USB-C cable (1 m), 2.4 GHz dongle.

## Compatibility

Works with Windows, macOS, Linux and iPadOS. The configurator for DPI steps and
button mapping is Windows and macOS only; the mouse keeps its settings when moved
to another operating system.

## Known issues

Left-handed users should note the side buttons are on the left side only; there
is no ambidextrous variant.
