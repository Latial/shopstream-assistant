# Aurora Headphones (SKU-4417)

Over-ear wireless headphones with active noise cancellation, tuned for long
listening sessions.

**Price: €149**

## Specifications

| Attribute | Value |
|---|---|
| Type | Over-ear, closed back |
| Battery life | 30 hours (ANC on) |
| Charging | USB-C, 2 hours to full, 10-minute quick charge for 4 hours |
| Noise cancellation | Hybrid ANC, up to 25 dB |
| Bluetooth | 5.3, SBC and AAC |
| Weight | 250 g |
| Colours | Black, Sand |

## In the box

Headphones, USB-C charging cable (1 m), 3.5 mm audio cable, fabric carry pouch,
quick start guide.

## Compatibility

Works with any Bluetooth audio device. The Aurora companion app is available for
iOS, Android and Windows and is required for firmware updates and EQ presets.

## Known issues

Firmware 1.2 resolved intermittent Bluetooth dropouts reported on Windows 11
laptops using certain Intel adapters. If you see dropouts, update the firmware
through the companion app.
