# Vertex 7-in-1 USB-C Hub (SKU-5502)

Aluminium USB-C hub for laptops and tablets.

**Price: €59**

## Specifications

| Attribute | Value |
|---|---|
| Ports | 2× USB-A 3.2, 1× USB-C data, HDMI, SD, microSD, USB-C PD in |
| Power delivery | 100 W pass-through (up to 85 W to the host) |
| HDMI | 4K at 60 Hz |
| Cable | 18 cm captive USB-C |
| Weight | 92 g |

## In the box

Hub, travel pouch, quick start guide.

## Compatibility

Requires a host USB-C port with DisplayPort Alt Mode for HDMI output. HDMI output
does not work on hosts without Alt Mode, including some tablets and older laptops
— check your device's specification before ordering.

## Known issues

Some 4K 60 Hz monitors need a certified High Speed HDMI cable; the cable is not
included. The hub becomes warm under sustained 100 W pass-through, which is
normal.
